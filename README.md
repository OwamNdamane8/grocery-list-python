# Grocery List Builder

A simple Python program that builds a shopping list from user input.

## Features
- Add grocery items one at a time
- Ignores blank entries and duplicate items
- Type `stop` to finish
- Displays a numbered list with the total number of items

## How to run
1. Make sure Python 3 is installed.
2. Download `grocery.py`.
3. Open a terminal in the same folder and run `python grocery.py`, or open the file in Thonny and click **Run**.

## Example
```
Type in an item (or 'stop' to finish): milk
milk added.
Type in an item (or 'stop' to finish): bread
bread added.
Type in an item (or 'stop' to finish): milk
milk is already on your list.
Type in an item (or 'stop' to finish): stop

Your grocery list:
1. milk
2. bread
Total items: 2
Thank you for using our app
```
